# 信用卡尺寸屏幕宏键盘 / USB 麦克风 — 产品需求文档（草案）

## 1. 产品概述

设计一款桌面有线输入设备，整体正面投影不超过标准信用卡（ID-1）尺寸。设备上半部为彩色屏幕，下半部横向排列 4 个实体按键，核心控制器基于 Seeed Studio XIAO 系列开发板/模块，通过 USB-C 连接电脑。

设备连接电脑后，应同时提供：

1. USB HID 键盘功能，用于发送按键、组合键或宏命令；
2. USB 麦克风功能，作为电脑可选择的单声道音频输入设备；
3. 屏幕显示功能，用于显示按键标签、状态、音量/静音状态或自定义图形。

参考外观采用上传草图所示的“上方大屏幕、下方四键”布局。

## 2. 目标用户与使用场景

- 桌面快捷键、直播控制、会议控制和常用宏操作；
- 通过设备内置麦克风进行语音通话、简单录音或语音指令输入；
- 屏幕动态显示四个按键当前映射、应用状态和麦克风状态；
- 使用单根 USB-C 线完成供电、键盘通信和麦克风音频传输。

## 3. 外形与布局要求

### 3.1 外形包络

- 正面最大尺寸：**85.60 mm × 53.98 mm**（标准 ID-1 信用卡尺寸）。
- 默认方向：横向使用，85.60 mm 为左右方向，53.98 mm 为上下方向。
- 厚度目标：成品主体不超过 **12 mm**；键帽最高点可在机械设计阶段进一步优化。该厚度为暂定工程目标，不等同于信用卡厚度。
- 外壳四角应圆滑，便于手持和桌面使用。
- 默认不包含电池；设备仅由 USB 供电。

### 3.2 正面布局

- 上方设置一块彩色 TFT 屏幕，占据主要显示区域。
- 下方设置 4 个独立实体按键，默认横向单排、等间距排列。
- 每个按键应可被清楚识别并可单手按下，按键之间应避免误触。
- 屏幕默认不要求触摸功能。
- 麦克风声孔不得被屏幕、键帽或手指常规操作位置完全遮挡。

### 3.3 接口位置

- 设置 1 个用户可直接插拔的 USB-C 接口，优先布置在短边侧面，以减少对正面布局的占用。
- USB-C 插头插入后不应与按键操作干涉。
- USB-C 接口必须提供机械支撑，不能只依赖细小焊盘承受插拔载荷。

## 4. 核心功能需求

### 4.1 键盘功能

- 4 个实体按键均可独立检测。
- 设备应枚举为标准 USB HID 键盘，无需专用驱动即可完成基本输入。
- 每个键应支持至少一种键盘键值、组合键或宏命令。
- 默认按键功能可在固件阶段定义；最终产品宜支持通过固件配置修改映射。
- 按键输入必须进行可靠消抖，单次按压不得产生非预期重复触发。

### 4.2 麦克风功能

- 设备应枚举为标准 USB Audio Class 麦克风，并可与 USB HID 功能同时工作。
- 音频输入：单声道。
- 目标采样能力：至少 **16-bit / 16 kHz**；优选支持 **16-bit / 48 kHz**，最终以所选 XIAO、麦克风和 USB 固件资源验证为准。
- 麦克风应适用于桌面近场语音；不将专业录音棚音质、波束成形或主动降噪列为本版要求。
- 屏幕应能显示麦克风启用/静音状态；四键中的具体哪一键负责静音由固件映射决定。

### 4.3 屏幕功能

- 目标显示模组：用户提供资料中的 **LT225C7-C08-03，2.25 英寸 TFT LCD Module**。
- 硬件阶段必须依据完整规格书核对模组外形、有效显示区、FPC/连接器、接口电压、显示接口、背光要求和初始化参数，不能仅凭型号推断。
- 屏幕应能显示四个按键的当前标签或功能，以及 USB/麦克风状态。
- 在正常室内桌面环境下，显示内容应清晰可辨。
- 若指定模组的完整机械包络无法与四键、XIAO 和 USB-C 同时放入信用卡尺寸内，应返回需求评审，不得自行改用更小屏幕。

### 4.4 USB 与供电

- 对外连接器为 USB-C，连接电脑后由 VBUS 供电。
- 设备必须能够作为复合 USB 设备同时提供 HID 键盘与 USB 麦克风功能。
- 不要求 USB Power Delivery；默认采用 5 V USB 供电。
- USB-C 设备端应包含正确的连接检测/下拉配置及必要的 ESD/过流风险控制，具体电路在硬件阶段确定。
- 典型工作时不得超过普通电脑 USB 端口可提供的电流；屏幕背光应允许固件调节亮度以控制功耗。

## 5. 控制器要求

- 产品基于 **Seeed Studio XIAO 系列**。
- 具体 XIAO 型号在硬件阶段选定，必须满足：
  - 原生或可靠支持 USB 设备模式；
  - 能同时实现 USB HID 与 USB Audio Class；
  - 具备驱动 TFT 所需的高速数字接口；
  - 具备连接数字麦克风所需的音频接口或足够性能的替代方案；
  - 为 4 个独立按键保留足够 GPIO；
  - RAM、Flash 和处理性能足以支持显示刷新、USB 音频和按键扫描并行运行。
- 不允许仅因“属于 XIAO 系列”就认定兼容，选型必须有固件栈和引脚资源证据。

## 6. 机械与装配需求

- 产品应包含定制 PCB 与保护电子器件的外壳/结构件。
- 屏幕、XIAO、按键、麦克风和 USB-C 接口应具有明确固定方式和装配顺序。
- 外壳应提供屏幕窗口、四键开口、麦克风声孔和 USB-C 开口。
- 正常按键操作和 USB-C 插拔不应导致 PCB 或屏幕明显弯曲。
- 成品底面应能稳定放置在桌面，宜预留防滑脚或防滑垫位置。
- 外壳材料与制造方式在后续机械阶段确定，原型优先考虑可制造、可拆装方案。

## 7. 体验与外观要求

- 正面视觉应简洁，屏幕与四键保持居中、规则对齐。
- 开机后屏幕应在合理时间内显示状态，目标不超过 3 秒。
- 按键反馈应明确；具体开关类型、键程和按压力在硬件阶段确定。
- 产品不依赖无线连接、手机应用或电池即可完成核心功能。

## 8. 验收标准

1. 成品正面外形不超过 85.60 mm × 53.98 mm。
2. 电脑通过单根 USB-C 线连接后，设备可稳定枚举为键盘和麦克风。
3. 四个实体按键均可独立触发预设 HID 输入，无明显误触或异常连击。
4. 麦克风可被主流桌面操作系统选为音频输入，并完成连续语音采集。
5. 键盘输入、屏幕刷新与音频采集同时运行时，设备不应频繁断连、重启或出现明显音频中断。
6. 屏幕能显示按键标签及麦克风状态。
7. USB-C 插拔、正常按键操作和轻度桌面搬动不会造成内部器件松脱。
8. 结构布局与上传草图保持一致：屏幕位于上方，四键位于屏幕下方。

## 9. 已采用的工程假设

- “信用卡大小”按 XY 外形包络理解，不要求达到 0.76 mm 的信用卡厚度。
- 默认横向布局，四键为单排。
- 默认使用有线 USB 供电，无电池、无线和触摸屏。
- “可以当麦克风”解释为电脑可识别的 USB 麦克风，而不是只在设备内部进行声级检测。
- 指定 LT225C7-C08-03 为目标屏幕；因当前项目中仅能读取到规格书摘要，完整尺寸和引脚信息必须在硬件阶段重新取得并核验。

## 10. 后续阶段待决事项

以下事项不阻碍本 PRD 评审，但必须在硬件/BOM 阶段关闭：

- 确定满足复合 USB HID + Audio、显示和音频接口要求的具体 XIAO 型号；
- 核验 LT225C7-C08-03 的完整机械图、FPC 引脚、逻辑电压、背光与显示驱动要求；
- 选择按键类型、键帽尺寸、数字麦克风和 USB-C 结构方案；
- 根据真实器件包络验证 12 mm 厚度目标和信用卡平面尺寸可实现性；
- 确认目标操作系统范围及最终 16 kHz / 48 kHz 音频档位。
