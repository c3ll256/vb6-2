# 信用卡尺寸四键屏幕麦克风键盘 — 产品需求文档

## 1. 产品概述

设计一款横向信用卡尺寸的桌面 USB 复合输入设备。设备基于 Seeed Studio XIAO 系列控制器平台，正面上半部为显示屏，下半部横向排列 4 个矮轴机械按键；通过 USB‑C 连接电脑，同时作为键盘类 HID 设备和 USB 麦克风使用。

本 PRD 依据用户描述及参考草图 `references/uploads/20260724T161051022Z-1-drawing-2026-07-24t16-10-41-669z.png` 编写。草图表达的主要布局为：横向矩形机身、上方大面积屏幕、屏幕下方一排四键、底边 USB‑C 接口。

## 2. 目标用户与使用场景

- 桌面快捷键/宏操作。
- 视频会议、语音聊天或简单语音输入。
- 屏幕显示设备状态、按键功能或麦克风状态。
- 由电脑 USB 供电，不依赖电池即可完成核心功能。

## 3. 外形与布局

- 机身平面外廓目标：ISO/IEC 7810 ID‑1 信用卡尺寸，**85.60 mm × 53.98 mm**，允许外壳圆角但不得扩大名义长宽。
- 使用方向：横向。
- 正面上区：单块显示屏，尽可能利用可用宽度，同时为边框、固定结构和走线留出空间。
- 正面下区：4 个等间距横排矮轴机械按键，配套矮轴键帽。
- USB‑C 插口：位于底边，优先居中；插头插拔时不得与键帽或外壳干涉。
- 麦克风拾音孔：布置在正面或上边缘，不能被手指、键帽或桌面遮挡。
- 整机厚度目标：在矮轴开关、键帽及结构允许下尽量薄，工程目标不超过 **18 mm**（不含按键按下行程），最终由 BOM/PCB/CAD 堆叠验证。

## 4. 核心功能

### 4.1 USB 连接

- 通过设备上的 USB‑C 连接电脑并取电。
- 连接后同时枚举为 USB HID 键盘与 USB Audio Class 麦克风；无需专用驱动即可在主流桌面系统上完成基础使用。
- 单根 USB 线同时承担供电、按键数据和音频数据。

### 4.2 四键输入

- 4 个独立矮轴机械按键均可由固件定义键值或宏。
- 支持单键触发；不得出现正常操作下的漏触发或粘连。
- 四键均为可编程宏键；出厂默认映射中，一键用于切换 USB 麦克风静音，其余三键提供常用宏示例，所有映射均可由固件配置。

### 4.3 显示

- 指定屏幕为用户提供资料中的 **LT225C7-C08-03 2.25 英寸彩色 LCD**。
- 依据该屏幕数据手册第 4 页：模组尺寸 17.9 mm × 62.5 mm × 2.36 mm，显示区域 14.7972 mm × 55.2948 mm，原生分辨率 76(H)RGB × 284(V)，4 线 SPI，ST7789P3 驱动，262K 色。产品中将模组旋转为横向长条显示，以匹配草图的上方屏幕区域。
- 屏幕在 USB 供电后显示可读信息，至少显示连接状态、四键当前功能提示和麦克风静音状态。

### 4.4 麦克风

- 设备向电脑提供单声道 USB 麦克风输入。
- 面向桌面近讲场景，正常距离约 30–60 cm 时语音应清晰可辨。
- 四个机械键中的一个在默认映射下切换麦克风静音，屏幕必须同步提供明确的静音状态反馈。
- 麦克风、音频前端及具体 XIAO 型号在 BOM 阶段根据 USB 音频能力、引脚和空间完成选型。

## 5. 平台与实现约束

- 主控平台必须采用 **Seeed Studio XIAO 外形/生态**；具体 XIAO 型号为 BOM 阶段的设计关键选择，闭环条件为同时满足 USB HID + USB Audio、显示接口、4 键扫描、尺寸和供货要求。
- 采用定制 PCB，将 XIAO、显示屏接口、麦克风、4 个开关及必要的电源/保护器件集成在信用卡外形内。
- USB‑C 为连接电脑的外部数据/供电接口；不得仅实现充电。
- 核心功能在总线供电下可用，不设置电池为本版必需项。

## 6. 兼容性与体验

- 目标主机：Windows 11、macOS 及常见 Linux 桌面系统。
- 基础键盘与麦克风功能应使用系统标准类驱动。
- 插入 USB 后，用户无需拆机或拨动内部开关即可使用。
- 麦克风静音状态必须同时对用户可见，避免“界面显示未静音但实际静音”或相反的歧义。

## 7. 可靠性与安全

- USB 接口应考虑 ESD 防护、连接器固定强度及反复插拔受力。
- 键轴应可承受正常桌面反复按压；外壳不得因按键操作明显翘曲。
- 麦克风孔应有基本防异物设计，但不得显著阻塞拾音。
- 不宣称专业录音、医疗、听力辅助或防水能力。

## 8. 验收标准

1. 完整机身平面包络不超过 85.60 mm × 53.98 mm。
2. 正面具有一块可工作的屏幕与其下方横排 4 个矮轴机械按键。
3. 通过一根 USB‑C 数据线连接电脑并由 USB 供电。
4. 电脑可同时识别标准键盘和标准 USB 麦克风。
5. 四键均能独立触发设定的键值/宏；连续操作无明显漏触发。
6. 30–60 cm 桌面近讲时，可在系统录音输入中获得清晰可辨的单声道语音。
7. 屏幕能显示连接状态、四键功能提示和麦克风静音状态。
8. USB 插头、键帽、屏幕边框和拾音孔之间无机械干涉。
9. 基础功能在 Windows 11、macOS 和常见 Linux 桌面系统上无需专用驱动。

## 9. 已确认的产品选择

- 屏幕：LT225C7-C08-03 2.25 英寸彩色 LCD；数据手册来源为 `artifacts/pdfs/lt225c7-c08-03.pdf`。
- 四键：全部为可编程宏键。
- 麦克风静音：默认占用四个机械键中的一个作为静音切换键，屏幕同步显示状态。

## 10. 下游交接

- **BOM 阶段负责**：确定具体 XIAO 型号、LT225C7-C08-03 的精确采购项与连接器/排线实现、数字/模拟麦克风及音频链路、矮轴规格、USB‑C 连接器和保护器件；所有器件必须通过尺寸、引脚与接口闭环后方可标记 BOM ready。
- **PCB 阶段负责**：在信用卡外形中完成电气连接、布局、USB/音频完整性、开关定位、显示连接与机械禁布区。
- **CAD 阶段负责**：依据最终 PCB fabrication STEP 设计薄型外壳、屏幕窗口、四键开口、麦克风声孔、USB‑C 开口和装配维护结构。
